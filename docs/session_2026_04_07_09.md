### 4. NeMo + CosyVoice Torch Conflict (CRITICAL FAILURE)

Attempted to install `nemo_toolkit[asr]` in cosyvoice_env to support
ParakeetTranscriber. **This silently broke the environment:**

- NeMo requires `torch>=2.6.0`
- CosyVoice was pinned to `torch==2.3.1+cu121`
- pip silently upgraded torch to 2.11.0 and pulled CUDA 13 libraries (~3 GB)
- Also upgraded: pydantic 2.7.0 -> 2.12.5, pyarrow 18 -> 23, protobuf 4.25 -> 5.29, triton 2.3.1 -> 3.6.0
- **CosyVoice cannot run on torch 2.11** (Matcha-TTS internal hooks break)

**Root cause**: NeMo and CosyVoice have mutually exclusive torch version
requirements. They **cannot coexist in one venv**.

### 5. CosyVoice Environment Rebuild (Second Attempt - In Progress)

Nuked the broken env and rebuilt with **torch 2.6.0+cu124** as a compromise:
- Satisfies NeMo's `torch>=2.6.0` requirement
- Newer than CosyVoice's conservative 2.3.1 pin but expected to work (community-verified)
- CUDA 12.4 wheels compatible with driver 560.35.03

```bash
deactivate
rm -rf ~/ANTI-SPOOFING-VOICE-LATIN-AMERICA/envs/cosyvoice_env
python3.10 -m venv ~/ANTI-SPOOFING-VOICE-LATIN-AMERICA/envs/cosyvoice_env
source ~/ANTI-SPOOFING-VOICE-LATIN-AMERICA/envs/cosyvoice_env/bin/activate
pip install --upgrade pip setuptools wheel

# Constraint file to prevent torch overrides
cat > /tmp/torch_constraints.txt <<'EOF'
torch==2.6.0
torchaudio==2.6.0
torchvision==0.21.0
EOF

# Install torch 2.6.0 with CUDA 12.4
pip install torch==2.6.0 torchaudio==2.6.0 torchvision==0.21.0 \
  --index-url https://download.pytorch.org/whl/cu124
```

## Key Decisions

| Decision | Rationale |
|----------|-----------|
| torch 2.6.0+cu124 as compromise | Satisfies both NeMo (>=2.6) and CosyVoice (community-verified on 2.6). cu124 works on driver 560. |
| Constraint file for torch | Prevents pip from silently upgrading torch during NeMo or CosyVoice dep installs. |
| GPU 0 only | GPUs 1 and 3 in use by other researchers' americasnlp jupyter notebooks. |
| Validation mode first, tmux for production | Validation is fast (3 speakers, ~6 samples). Production runs will use tmux detached. |
| Parakeet for all pipelines except Qwen | Qwen already uses faster-whisper and is done. Other pipelines get Parakeet for consistency. |

## Key Discoveries

| Discovery | Impact |
|-----------|--------|
| NeMo requires torch>=2.6, CosyVoice pins 2.3.1 | Cannot naively install both. torch 2.6 is the compromise version. |
| CosyVoice `frontend.py` hard-imports openai-whisper | Must install whisper in cosyvoice_env even though we use Parakeet for our transcription. It is a CosyVoice internal dependency. |
| wetext frontend downloads ~10 FST files on first model load | First CosyVoice model instantiation takes extra time (modelscope.cn downloads). |
| `pip install nemo_toolkit[asr]` silently upgrades torch | Must always use `--constraint` to lock torch version when installing NeMo. |
| Only Qwen and CosyVoice pipelines used Whisper for reference transcription | FishGram, Chatterbox, OpenVoice, OuteTTS don't do reference transcription via Whisper. |
