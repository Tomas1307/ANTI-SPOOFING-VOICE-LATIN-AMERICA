## What Was Done

### 1. Confirmed CosyVoice Dropped (Prior Session Finding)

CosyVoice2-0.5B does NOT support Spanish. Generates Chinese-sounding audio for
Spanish text input. This was confirmed in the prior session (April 7-9) with
Parakeet transcribing generated audio as English gibberish ("Oh like over tip
or"). Master Tomas confirmed by ear: "sounds like chinese." Valid research
finding -- documented as a negative result.

### 2. Diagnosed OuteTTS Model Version Mismatch

The CUDA assertion error `indexSelectSmallIndex: srcIndex < srcSelectDimSize`
indicated that the OuteTTS-0.3-500M model was generating token IDs outside the
vocabulary bounds of the DAC codec in outetts 0.4.4.

Investigation of `outetts.Models` enum revealed available versions:
```
VERSION_0_1_SIZE_350M, VERSION_0_2_SIZE_500M, VERSION_0_3_SIZE_1B,
VERSION_0_3_SIZE_500M, VERSION_1_0_SIZE_0_6B, VERSION_1_0_SIZE_1B
```

The v0.3 models use an older codec incompatible with library v0.4.4.
The v1.0 models are designed for the current library version.

### 3. Researched OuteTTS 1.0 0.6B

Key findings:
- **HuggingFace ID**: `OuteAI/OuteTTS-1.0-0.6B`
- **Architecture**: Qwen3 0.6B backbone (continued pre-training + fine-tuning)
- **Language support**: 14 languages including **Spanish** (trained on MLS + Common Voice)
- **API change**: v1.0 requires `InterfaceVersion.V3` and `Backend.HF`. The
  recommended approach is `ModelConfig.auto_config()` which handles this
  automatically.
- **Sampling**: Same parameters work (temp=0.4, top_k=40, top_p=0.9, rep_penalty=1.1).
  Repetition penalty applied to 64-token recent window only (library handles this).
- **License**: Apache 2.0

## Key Decisions

| Decision | Rationale |
|----------|-----------|
| OuteTTS 1.0 0.6B over v0.3-500M | v0.3 codec incompatible with outetts 0.4.4 library. v1.0 designed for current library, supports Spanish natively. |
| `auto_config()` over manual ModelConfig | Handles InterfaceVersion.V3, Backend.HF, and codec config automatically. Less fragile than manual wiring. |
| GPU 1 for this session | GPU 0 had existing 1280 MiB process. |
| CosyVoice dropped entirely | Only supports 5 languages (zh/en/ja/yue/ko). No Spanish. Outputs Chinese for Spanish text. Valid negative research finding. |

## Key Discoveries

| Discovery | Impact |
|-----------|--------|
| OuteTTS-0.3-500M incompatible with outetts 0.4.4 | CUDA assertion errors from DAC codec vocabulary mismatch. Must use v1.0 models. |
| OuteTTS 1.0 0.6B supports Spanish natively | Trained on 14 languages including Spanish via MLS + Common Voice. |
| `auto_config()` is the recommended model init pattern | Replaces manual model_path/tokenizer_path with enum-based config. |
| OuteTTS speaker similarity is moderate (~0.47 avg) | Lower than other attacks. Expected given 3s reference + autoregressive LLM approach. |
| NISQA MOS is excellent (4.62 avg) | Audio quality is high despite moderate speaker similarity. |
| pipeline_facade.py needed `__main__` guard | `python -m` exits silently without it. Other pipelines (fishgram, qwen, etc.) also lack this. |
| CosyVoice2-0.5B: zh/en/ja/yue/ko ONLY | No Spanish, no way around it. Not a config issue -- fundamental model limitation. |
