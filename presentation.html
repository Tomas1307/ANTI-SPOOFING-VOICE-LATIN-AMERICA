Pipeline 01 — Mozilla Speaker Selection

Architecture

Selects acoustically-valid Spanish speakers from Mozilla Common Voice v24.0 and integrates them as new bonafide HABLA speakers — physically copied, renumbered in HABLA-style IDs, split 70/15/15.

01
Extract HABLA Embeddings
HablaEmbeddingExtractor · step_01_extract_habla_embeddings.py
Loads up to 20 audio samples per speaker from the 162 existing HABLA speakers. ECAPA-TDNN (192-dim, speechbrain/spkrec-ecapa-voxceleb). Per-speaker mean embedding, L2-normalized. Output: habla_embeddings.npy (162, 192)
02
Extract CV Embeddings
CVEmbeddingExtractor · step_02_extract_cv_embeddings.py
Parses CV v24.0 validated.tsv (436,590 rows). One ECAPA-TDNN embedding per candidate — from their first validated sample. Output: cv_embeddings.npy (N_cv, 192)
03
Filter by Similarity
SimilarityFilter · step_03_filter_by_similarity.py
Full cosine similarity matrix CV @ HABLA.T → (N_cv × 162). Per CV speaker: take max_sim across all 162 HABLA speakers. Reject if max_sim ≥ 0.75. Output: filtered_speakers.json — 3,299 speakers pass.
04
Balanced Sampling
BalancedSampler · step_04_balanced_sampling.py
Stratified sampling across 5 accents and gender/age groups, targeting 15,340 total samples. Colombia and Chile top up existing HABLA counts to 5,450 each. Mexico and Spain are entirely new accents. Output: selected_15340.tsv
05
Integrate CV Samples
DatasetIntegrator · step_05_integrate_cv_samples.py
Copies all 162 HABLA speakers into bonafide_dataset_by_speaker_v2/ via shutil.copytree. Each new CV speaker gets a HABLA-style ID (e.g. mxm_00163) continuing the max index per accent+gender. Split: 70% train / 15% val / 15% test. Mapping saved to cv_speaker_mapping.json.

Pipeline 01 — Design Decision

Duplicate prevention

CV speakers have hashed client_ids — no overlap with HABLA-style speaker IDs. Speaker-ID matching is impossible. Acoustic similarity is used instead.

Three-step gate

01
HABLA reference embeddings
192-dim ECAPA-TDNN, averaged over ≤20 utterances per speaker, L2-normalized. Matrix: (162, 192).
02
CV candidate embeddings
Same ECAPA-TDNN model. One embedding per candidate from their first validated audio. Matrix: (N_cv, 192).
03
Cosine similarity gate
Full matrix CV @ HABLA.T → (N_cv × 162). Per CV speaker: max_sim across all 162. Reject if max_sim ≥ 0.75.

Code

# settings.py
SIMILARITY_THRESHOLD = 0.75

# step_03_filter_by_similarity.py
sim_matrix = cv_embs @ habla_embs.T
# shape: (N_cv, 162)

max_sim = sim_matrix.max(axis=1)
# one score per CV speaker

passed = max_sim < SIMILARITY_THRESHOLD
# must be distant from ALL 162
A CV speaker must be acoustically distant from every one of the 162 HABLA speakers — not just those from the same accent region.
Pipeline 02 — FishGram Attack

Fish Speech 4B

Primary attack pipeline. Zero-shot voice cloning via Fish Speech (OpenAudio-S1, 4B params, VQGAN vocoder) — running as a persistent HTTP API on ml-server03. Produces 80% of total attacks.

01
Prepare References
ReferenceAudioPreparator
First 5 training samples per speaker concatenated (alphabetical sort → deterministic) into a single 15-second reference clip.
02
Prepare Texts
TextPromptPreparator
Mozilla CV Spanish transcripts filtered to 5–100 words. Assignment via np.random.seed(42) — fully deterministic across runs.
03
Generate Speech HTTP API
SpeechGenerator
POST /v1/tts — base64 reference audio + text. Model (~12GB VRAM) runs as a persistent server. Pipeline is decoupled from model lifecycle — no reload per request.
04
Validate Quality
QualityValidator
DNSMOS ≥ 3.5. Speaker similarity ≥ 0.65 (ECAPA-TDNN cosine). Silence rejection: >1s consecutive silence → discard.
05
Format Output
OutputFormatter
WAV → FLAC. ASVspoof2019 LA protocol. System ID: FISHGRAM. Audio IDs: LA_T_9000001+
Pipeline 03 — Qwen Attack

Qwen3-TTS 1.7B

Secondary attack pipeline. Same output volume as FishGram but a completely different codec architecture — Dual-Track vs VQGAN. A detector trained on both cannot overfit to a single synthesis fingerprint.

01
Prepare References + STT vs FishGram
ReferenceAudioPreparator (with faster-whisper)
Same 15s clip assembly, but also transcribes the reference audio using faster-whisper large-v3 (Spanish). reference_text stored in metadata. Whisper model is a lazy singleton — loaded once, shared across all speakers.
02
Prepare Texts Max 40 words
TextPromptPreparator
Stricter limit than FishGram (100 words). Qwen3-TTS silently truncates audio on longer inputs without raising exceptions — the 40-word cap prevents that failure mode entirely.
03
Generate Speech Local model
SpeechGenerator
Loads Qwen3-TTS-12Hz-1.7B-Base directly into GPU. Speaker prompt computed once per speaker via create_voice_clone_prompt(), reused across all 5 samples — avoids 810 redundant feature extractions. Providing ref_text enables full cloning mode (x_vector_only_mode=False).
04
Validate + Artifact Detection Enhanced
QualityValidator
Standard DNSMOS + speaker similarity, plus Qwen-specific checks: duration outside 0.5–30s → reject. RMS < 0.001 → reject. Audio suspiciously short for text length → reject.
05
Format Output
OutputFormatter
WAV → FLAC. ASVspoof2019 LA. System ID: QWEN3TTS. Audio IDs: LA_T_8000001+ — no collision with FishGram range.
