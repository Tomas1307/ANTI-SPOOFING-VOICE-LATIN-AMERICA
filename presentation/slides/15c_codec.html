Augmentation — Layer 2: Codec degradation

The transmission channel: real telephony and VoIP codecs

Each clip is encoded and decoded through a real codec (not a hand-rolled approximation) using ffmpeg via torchaudio.io.AudioEffector. The set spans the full threat range: narrowband telephony and broadband VoIP. A runtime probe disables any codec the host ffmpeg build lacks, so the corpus only uses what is genuinely available.
