Bug 1 — watermark leak
All OpenVoice samples carried a hidden WavMark (“@MyShell”) baked into the waveform — a shortcut a detector could learn instead of the synthesis artifact.

Fix: watermark disabled, OpenVoice regenerated clean (29,796). Metrics unchanged → quality-neutral.
Bug 2 — partial-spoof miscount
We had reported 86,766 — a raw file count that included intermediates.

Fix: the authoritative spliced-sample count is 18,421 (from corpus_samples.csv). Corrected everywhere in the paper.
Decision — quality over quantity. Each bonafide file is attacked by one weighted system (not all six), and clones must pass an ECAPA ≥ 0.60 gate. We keep the gated 18,421, deposit all of it, and recommend the 15,641 that also pass the full-spoof intelligibility gate (WER ≤ 0.15, CER ≤ 0.10).
